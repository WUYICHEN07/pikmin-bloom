# PRD — 皮克敏水性類型運動換算步數系統

> **文件版本**：v1.0  
> **建立日期**：2026-05-09  
> **狀態**：草稿  

---

## 1. 專案概述

### 1.1 背景與動機

《Pikmin Bloom》是一款結合現實步行運動的 AR 手機遊戲，玩家透過日常走路來培育皮克敏、收集花瓣。然而，許多熱愛水上運動（游泳、划船、水球等）的玩家，其主要運動方式無法被手機計步器正確紀錄，導致大量運動成果在遊戲中無法體現。

本專案旨在建立一套**第三方運動數據轉換系統**，讓水上運動選手能將穿戴裝置記錄的游泳數據（如游泳時數、划水次數、距離等）自動換算為等量的皮克敏步數，並提供皮克敏風格的視覺化追蹤介面，提升遊戲體驗感。

### 1.2 目標用戶

| 用戶類型 | 描述 |
|---------|------|
| 水上運動玩家 | 以游泳、水上划船等為主要運動方式的《Pikmin Bloom》玩家 |
| 多運動型玩家 | 同時進行陸上與水上運動，希望完整記錄所有運動的玩家 |
| 運動教練/團體 | 希望透過遊戲化方式激勵選手訓練的教練或社團 |

### 1.3 核心價值主張

- **公平性**：讓水上運動的努力也能在皮克敏世界中被認可
- **便利性**：一鍵完成數據轉換，運動後不費力
- **趣味性**：保留皮克敏風格的視覺體驗，讓換算過程也充滿樂趣
- **安全性**：保護使用者的運動健康數據隱私

## 2. 功能需求

### 2.1 主要功能列表

#### 功能一：運動數據接入

**說明**：對接穿戴裝置數據，支援模擬上傳游泳時數、划水次數、游泳距離等水上運動數據。

**使用者故事**：  
> 作為一名**游泳選手玩家**，我希望能**將我的運動手錶數據上傳到系統中**，以便**我的水上運動紀錄能被系統識別並用於步數轉換**。

**功能細節**：
- 支援手動輸入運動數據（游泳時間、划水次數、距離）
- 支援模擬 CSV / JSON 格式的穿戴裝置數據匯入
- 預留 API 接口供未來對接 Garmin / Apple Health / Google Fit 等平台
- 資料驗證機制，防止異常數值輸入（例如負值、超出合理範圍）

---

#### 功能二：步數轉換引擎

**說明**：根據運動類型與強度，將游泳數據自動轉換為等量皮克敏步數。

**使用者故事**：  
> 作為一名**水上運動玩家**，我希望系統能**根據我的游泳數據自動計算出對應的皮克敏步數**，以便**我不需要手動換算就能知道今天的運動量對應多少步**。

**功能細節**：
- 提供預設轉換公式（例如：1 分鐘游泳 ≈ 120 步、1 次划水 ≈ 2 步）
- 依據運動強度（低/中/高）調整轉換係數
- 支援多種水上運動類型的個別轉換規則（自由式、蛙式、仰式、蝶式、划船等）
- 轉換結果即時呈現，回應時間 < 2 秒

---

#### 功能三：進度追蹤看板

**說明**：以皮克敏遊戲風格顯示當前成長進度與已轉換的運動里程。

**使用者故事**：  
> 作為一名**皮克敏玩家**，我希望能**在一個視覺化看板上看到我的皮克敏因為我的游泳運動而成長的進度**，以便**我感受到運動帶來的成就感與遊戲樂趣**。

**功能細節**：
- 顯示今日/本週/本月累計轉換步數
- 皮克敏角色成長動畫（隨步數增加而變化）
- 運動里程的歷史折線圖/柱狀圖
- 支援設定每日步數目標與達成提醒

---

#### 功能四：個人化背景主題

**說明**：提供不同的背景主題供玩家自由切換，增加遊戲體驗與個人化感受。

**使用者故事**：  
> 作為一名**重視個人化體驗的玩家**，我希望能**選擇不同的背景主題（如海洋、湖泊、泳池等）來裝飾我的介面**，以便**我的使用體驗更符合自己的偏好與運動風格**。

**功能細節**：
- 提供至少 4 種預設背景主題（海洋深潛、淡水湖泊、泳池派對、河流探險）
- 背景主題影響整體 UI 配色與動畫風格
- 玩家可在設定頁面即時預覽與切換主題
- 預留自訂背景上傳功能（Nice to Have）

---

#### 功能五：使用者帳號與數據管理

**說明**：提供使用者註冊、登入、個人資料管理與運動紀錄查詢功能。

**使用者故事**：  
> 作為一名**常態使用者**，我希望能**擁有自己的帳號來保存所有運動紀錄與轉換歷史**，以便**我每次登入都能看到完整的運動累積成果**。

**功能細節**：
- 使用者註冊 / 登入 / 登出
- 個人資料設定（暱稱、慣用運動類型、偏好背景主題）
- 運動紀錄列表（含轉換前原始數據與轉換後步數）
- 資料匯出功能（CSV 格式）

---

#### 功能六：一鍵快速轉換

**說明**：提供簡化操作流程，讓運動後疲憊的選手能以最少步驟完成數據上傳與轉換。

**使用者故事**：  
> 作為一名**剛結束高強度訓練的游泳選手**，我希望能**一鍵上傳並轉換我的運動數據**，以便**我不需要在疲憊的狀態下進行繁瑣的操作**。

**功能細節**：
- 首頁提供「快速轉換」大按鈕
- 支援常用運動類型的快捷設定
- 記住上次使用的運動類型與參數
- 轉換完成後以動畫呈現結果摘要

## 3. 非功能需求

### 3.1 技術限制

| 項目 | 規格 |
|------|------|
| 後端框架 | Flask（Python） |
| 模板引擎 | Jinja2 |
| 資料庫 | SQLite |
| 前端技術 | HTML5 + CSS3 + JavaScript |
| 部署方式 | 本地開發 / 可擴展至雲端部署 |

### 3.2 效能需求

- 數據轉換計算回應時間 **< 2 秒**
- 頁面載入時間 **< 3 秒**（首次載入）
- 資料庫查詢回應時間 **< 1 秒**
- 系統應能承受至少 **50 位同時在線使用者**

### 3.3 安全性需求

- 使用者密碼採用 **bcrypt 雜湊加密** 儲存
- 敏感數據傳輸使用 **HTTPS**（部署時啟用）
- 實作 **CSRF Token** 防護表單攻擊
- 運動健康數據不對外暴露，僅限本人存取
- Session 管理採用安全 Cookie 設定

### 3.4 易用性需求

- 介面風格模仿皮克敏遊戲，色彩鮮明、圖示直覺
- 核心操作（上傳 → 轉換 → 查看結果）**不超過 3 步**
- 支援行動裝置瀏覽器的響應式設計（RWD）
- 提供操作引導 Tooltip 或首次使用教學

### 3.5 範圍排除

> ⚠️ **本系統不包含**：直接破解或對接任天堂《Pikmin Bloom》官方伺服器進行數據寫入。本系統定位為**第三方紀錄與模擬驗證工具**，所有轉換結果僅供個人參考使用。

## 附錄：步數轉換公式參考

以下為初步擬定的轉換基準，可依實際使用回饋調整：

| 運動類型 | 指標 | 轉換基準（每單位 → 步數） | 強度調整係數 |
|---------|------|-------------------------|-------------|
| 自由式游泳 | 每分鐘 | 120 步 | 低 ×0.8 / 中 ×1.0 / 高 ×1.3 |
| 蛙式游泳 | 每分鐘 | 100 步 | 低 ×0.8 / 中 ×1.0 / 高 ×1.3 |
| 仰式游泳 | 每分鐘 | 90 步 | 低 ×0.8 / 中 ×1.0 / 高 ×1.3 |
| 蝶式游泳 | 每分鐘 | 150 步 | 低 ×0.8 / 中 ×1.0 / 高 ×1.3 |
| 划船 | 每分鐘 | 80 步 | 低 ×0.8 / 中 ×1.0 / 高 ×1.3 |
| 划水次數 | 每次 | 2 步 | — |
| 游泳距離 | 每 100 公尺 | 200 步 | — |

> 💡 **備註**：轉換公式的目標是讓水上運動的步數產出與同等時間的步行運動大致對等，以確保公平性。
